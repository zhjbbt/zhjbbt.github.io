第一部分：在虚拟机中安装 Kali

第一步，获取 Kali 官方镜像。为避免误入第三方捆绑下载页，可直接让豆包检索 Kali 官方下载入口，再核对域名与版本信息。

本文示例选择 kali-linux-2026.3-installer-amd64.iso。版本会随时间更新，下载时以 Kali 官网当前稳定版为准。

开始下载，并记住镜像的保存路径，后面创建虚拟机时会用到。

打开 VMware。尚未安装 VMware 的读者，可先通过官方渠道下载安装。

点击“文件”，选择“新建虚拟机”。

点击“下一步”。

点击“下一步”。

客户机操作系统选择“Linux”，版本按镜像选择 Debian 64 位（如界面提供），然后点击“下一步”。

输入英文虚拟机名称，选择安装位置，再点击“下一步”。

根据实际需要设置磁盘容量，点击“下一步”。

点击“自定义硬件”，根据电脑配置调整资源。

按宿主机配置分配处理器、内存等资源。不要把内存分满，需给 Windows 留出足够运行空间。

网络模式选择“桥接”，方便宿主机与 Kali 在同一局域网内通信。若网络环境不允许桥接，也可改用 NAT。

确认配置无误后，点击“完成”。

启动虚拟机，进入 Kali 安装界面。

选择第一项，按回车确认。

接下来等待系统自动安装，按界面提示继续即可。

输入英文主机名，便于后续在局域网中识别这台设备。

点击“继续”。

设置登录用户名。

设置登录密码，并妥善保存。公开教程中请勿展示真实密码。

点击“继续”。

按界面提示选择“是”，再点击“继续”。

系统开始自动安装，耐心等待即可。

第二部分：完成 Kali 基础配置

安装完成后，虚拟机会自动重启。输入刚设置的账号和密码，登录 Kali。

进入 Kali 桌面，点击左上角的终端图标，打开命令行。

在终端依次执行以下命令，完成 SSH 安装与配置。每输入一条命令，按回车确认。

① 安装 openssh-server（部分新版 Kali 镜像可能未预装）sudo apt update

sudo apt install openssh-server -y

② 启动 SSH 服务，并设置开机自启sudo systemctl enable –now ssh

③ 查看 SSH 状态，确认服务正常运行sudo systemctl status ssh

看到服务状态正常，说明 SSH 已启动，可以关闭当前终端。

重新打开一个终端，输入以下命令查看本机 IP：

ip addr

本文示例中的局域网 IP 为 192.168.1.5。你的地址可能不同，请以实际查询结果为准。

③ 配置服务权限与开机自启

仅在隔离的自建靶场中配置 DSH 所需权限，并设置开机自启。权限应遵循最小化原则，不建议为了省事直接长期开放 root；同时绑定宿主机 IP，避免服务暴露到不受信任的网络。将下面的指令发给智能体：

选择“自定义模型”，填写宿主机本地模型地址和 API 参数。注意核对地址、端口和模型名称，避免连接失败。

点击“创建模型”，完成配置。
